# Sabu — releases

Installers and updates for the Sabu till.

A till installs and updates itself from here: it looks for the newest release,
downloads the installer and puts it on when nobody is signed in. There is
nothing to read here — the release notes below each version say what changed.

Sabu is built from the same codebase as POS Till, as a separate edition. The two
never meet: their own program, their own data folder, their own updates.
